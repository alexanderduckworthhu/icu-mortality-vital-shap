# ICU 48-hour mortality risk from vital signs, with window attribution

A Streamlit portfolio demo for clinical data science candidates:
calibrated 48-hour ICU mortality risk from vital-sign time series, plus SHAP
attribution showing which vital × lookback windows drove each estimate.

## Why it exists

A bare mortality probability can anchor care decisions and create false certainty.
Clinicians need a **calibrated** short-horizon estimate **and** an answer to
*which vital-sign windows pushed the score*, so they can agree, challenge, or
investigate. Existing MIMIC tutorials often stop at AUROC and skip calibration,
missingness honesty, and how the number should be spoken aloud.

---

## Technical decisions

- **Task: 48-hour mortality from the last 48 hours of vitals**, considered
  in-hospital or 30-day labels; chose 48h for actionable horizon and clearer
  vital dynamics without discharge confounding.
- **Signals: HR, SBP, DBP, RR, SpO₂, temperature only**, considered labs and
  interventions; deferred them to keep missingness auditable and scope entry-level.
- **Preprocess: plausibility → NaN, missingness flags, 2h forward-fill, train medians**,
  considered MICE; rejected for v1 because opaque fills are harder to defend in review.
- **Model v1: isotonic-calibrated L2 logistic on 6h/24h/48h window aggregates**,
  considered LSTM / gradient boosting first; logistic sets a discrimination and
  calibration floor with stable tabular SHAP.
- **Explain: KernelSHAP → vital × window heatmap**, considered coefficient plots
  alone; SHAP survives the calibration wrapper and maps to clinician language.
- **UI: Streamlit sidebar (EN/FR/DE/IT/PT/ES/AR/ZH/RU via `src/i18n.py`)**, same language-switcher pattern as Where Needs Overlap.
- **Public demo on synthetic stays**. MIMIC rows stay off public UIs until hosting
  is DUA-compliant.

Treat near-ceiling synthetic AUROC as a **pipeline check**, not clinical

## Setup & usage

```bash
cd icu-mortality-vital-shap
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m scripts.build_demo_data
python -m scripts.train_baseline
streamlit run app.py               # opens Streamlit locally

pytest
```

## What I'd improve next

1. **Patient-level MIMIC-III split with published AUROC / PR-AUC / ECE**, current
   public metrics are synthetic; reviewers will ask for real held-out numbers before presenting this work.
2. **Subgroup calibration (sex, age band, CareVue vs Metavision era)**, without it,
   a single ECE hides drift that matters for regulated health settings.
3. **LSTM only if error analysis shows missed trajectories**, checklist in
   `src/models/lstm.py`; keep attribution (gradient or DeepSHAP) before claiming
   sequence interpretability.
