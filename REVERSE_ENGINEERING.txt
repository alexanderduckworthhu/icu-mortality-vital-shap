--------------------------------------------------------------------------------
1. THE ONE IDEA (start here when lost)
--------------------------------------------------------------------------------
Question the whole app answers:

  "Given 48 hours of ICU vital signs, what is a calibrated estimate of
   48-hour mortality risk — and which vital-sign windows drove that estimate?"

If a feature does not improve honest risk estimation, attribution, calibration,
or uncertainty communication, it does not belong. That filter stops INFJ
overbuilding (no premature LSTM, no fake precision, no "AI doctor" chrome).

--------------------------------------------------------------------------------
4. THE FEATURE TABLE (decode the product)
--------------------------------------------------------------------------------
After train_baseline, conceptually you have rows like:

  stay_id, label,
  heart_rate_mean_6h, heart_rate_slope_6h, ...,
  spo2_mean_24h, spo2_missrate_24h, ...

Each column is a story you can tell a clinician. If you cannot say the story,
delete the column.

SHAP heatmap columns are 6h / 24h / 48h — the same windows. That alignment is
deliberate: explanation language matches feature language.


--------------------------------------------------------------------------------
5. REVERSE-ENGINEER DRILLS (do these once)
--------------------------------------------------------------------------------
A. Break plausibility
   Set a demo SpO2 to 0 before cleaning; confirm it becomes NaN and raises
   miss flags — not a "zero oxygen" feature.

B. Swap model off
   Temporarily skip calibration in train_baseline; compare ECE. Use the
   difference in interviews: "uncalibrated ranking ≠ usable probability."

C. Read one SHAP row aloud
   Pick top_drivers from a high-risk stay. Say: "The model increased risk
   because of X window — that may or may not match physiology; here's the
   trajectory so you can judge."

D. LSTM temptation test
   Open src/models/lstm.py. If you cannot tick the checklist with evidence,
   do not implement it yet. Portfolio maturity > architecture fashion.

E. Ethics read-through
   Click a high-risk demo stay. If the UI feels like a death sentence, the
   copy failed — fix framing.py, not the model.
